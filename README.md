# api-vault

คลัง API ส่วนตัว: แคตตาล็อก API ฟรี/สาธารณะ ค้นเป็นภาษาไทยได้ + ที่เก็บ API key แบบเข้ารหัส (envelope encryption)
สำหรับเจ้าของคนเดียว

Stack: Nuxt 4 · Nuxt UI · Supabase Postgres · Drizzle · Zod · Vitest · Vercel (`sin1`)

## ใช้งาน

ขั้นตอนตั้งแต่เข้าเว็บจนใช้ Key ในโค้ด: [`docs/RUNBOOK.md`](docs/RUNBOOK.md)
