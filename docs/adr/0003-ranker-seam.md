# ADR-0003: Ranker เป็น seam ที่สลับได้

- สถานะ: ยอมรับ · 2026-09-24

## บริบท
ตั้งใจใช้ Jev (TypeSafe) ค้นภาษาไทยด้วย 2 request (เลือกหมวด → เลือก Entry + "No match") แต่ TypeSafe
ปิดรับสมัคร (`signups_disabled`, 2026-09-23) ยังไม่มี key และยังไม่รู้ว่าความแม่นภาษาไทยผ่านเกณฑ์ไหม

## ตัดสินใจ
การค้นทั้งหมดผ่าน interface เดียว (`Ranker`: คำค้น → Entry เรียงลำดับ + ความมั่นใจ | No match) มี implementation:
1. **keyword ranker** (อังกฤษธรรมดา ไม่พึ่งบริการภายนอก) — v0.1.0
2. **Jev ranker** — ตัวหลัก เมื่อมี key และ spike ผ่าน **≥ 15/20 คำค้นไทยใน top-5**
3. **Claude structured output** — ตัวสำรองถ้า TypeSafe ยังปิดหรือ spike ไม่ผ่าน

เลือกตัวด้วย config ฝั่ง server · UI/หน้าเดโมไม่รู้ว่าข้างหลังเป็นตัวไหน

## ตัดสินเพิ่ม 2026-09-24 (v0.5.0)
- เพิ่ม **thai-dict ranker** (พจนานุกรมไทย→อังกฤษ + `Intl.Segmenter`) เป็นค่าเริ่ม — ผู้ใช้เลือกเพราะ**ไม่มีค่าใช้จ่าย**
  และค้นสดบน production ได้โดยไม่ต้องมี key · ข้อจำกัด: คำนอกพจนานุกรม = ไม่เจอ, เข้าใจประโยคซับซ้อนไม่ได้
- **claude ranker** เขียนเสร็จแต่ไม่เปิด (ค่าใช้จ่ายต่อการค้น) · Jev ยังเป็นเป้าหมายเมื่อ TypeSafe เปิด
- เกณฑ์ ≥ 15/20 ใช้กับทุก Ranker · คำค้นทดสอบต้องเขียนโดยผู้ใช้ ไม่ใช่คนเขียนพจนานุกรม (กันผลดีเกินจริง)

## ผลที่ตามมา
- งานที่ไม่ใช้ Jev เดินต่อได้ทันที
- Ranker รับได้แค่คำค้นและข้อมูล Entry — **ห้ามส่ง Key** (ADR-0002)
