# ADR-0004: เดโมสาธารณะใช้ผลที่คำนวณไว้แล้ว

- สถานะ: ยอมรับ · 2026-09-23 · บันทึก 2026-09-24

## ตัดสินใจ
หน้า `/demo` แสดงผลค้น **5–8 ข้อที่คำนวณไว้ล่วงหน้า** (ความน่าจะเป็น + ความมั่นใจ มีข้อ "No match" หนึ่งข้อ)
เป็นไฟล์ข้อมูลใน repo · prerender เป็น static · **ไม่ยิง Ranker สด ไม่มี Key หรือ secret ใดใน build**

## ทำไม
repo public + เดโมสาธารณะ: ยิงสด = ใครก็เผาโควตา/เงินได้ และต้องมี secret ใน deployment สาธารณะ

## ผลที่ตามมา
- ต้องมีเทสว่า output ของ build เดโมไม่มี secret (สแกนหา pattern ของค่าใน `.env`)
- ผลเดโมต้องสร้างใหม่เองเมื่อ Ranker เปลี่ยน
