# ADR-0007: v1.0.0 ไม่รอ Jev — thai-dict + เพิ่ม Entry เอง

- สถานะ: ยอมรับ · 2026-09-24

## บริบท
spec เดิมผูก v1.0.0 ไว้กับ Jev: ค้นไทย ≥ 15/20 · Tag อัตโนมัติ · เดโมใช้ผลของ Jev · ถ้า TypeSafe ยังปิดให้ใช้ Claude แทน
แต่ ณ 2026-09-24 (หลัง v0.5.1):
- TypeSafe ยังปิดรับสมัคร ไม่รู้ว่าจะเปิดก่อนเพดาน 2026-10-24 ไหม
- เจ้าของ**ยอมรับ thai-dict ที่ 14/20** (holdout3 ชุดที่ไม่เคยเห็น) และ**ไม่เปิด Claude ranker** เพราะมีค่าใช้จ่ายต่อการค้น
  (ADR-0003 ตัดสินเพิ่ม v0.5.0)

ถ้าไม่ตัดสินใหม่ v1.0.0 จะค้างถึงเพดานโดยไม่มีใครทำอะไรได้ ทั้งที่งานส่วน "เพิ่ม Entry เอง" ไม่ต้องพึ่ง Jev เลย

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| รอ Jev ตามเดิม | ตรง spec เดิม | ขึ้นกับบริษัทอื่น · อาจไม่มี v1.0.0 ภายในเพดาน |
| เปิด Claude ranker ตามแผนสำรอง | น่าจะผ่าน 15/20 | เจ้าของปฏิเสธแล้ว (ค่าใช้จ่ายต่อการค้น) |
| **v1.0.0 = thai-dict + เพิ่ม Entry เอง · Jev ไป V1.1** ✔︎ | ปิด V1 ได้ในเพดาน ไม่มีค่าใช้จ่าย | ค้นไทยแม่นแค่ 14/20 · ยังไม่มี Tag |

## ตัดสินใจ
**v1.0.0 = thai-dict เป็น Ranker ค่าเริ่ม + เจ้าของเพิ่ม Entry เองได้**

1. **เกณฑ์การค้น = กันถอยหลัง** — `npm run eval:ranker thai-dict spike/queries-holdout3.json` ต้อง ≥ 14/20
   (holdout3 ไม่ใช่ "ชุดที่ไม่เคยเห็น" อีกแล้ว — ใช้เป็นตัวกันถอยหลัง ไม่ใช่ตัววัดความแม่นจริง)
   · เกณฑ์ ≥ 15/20 ของ ADR-0003 ยังใช้กับ Jev ใน V1.1
2. **Tag อัตโนมัติย้ายไป V1.1** พร้อม Jev — Entry ที่เพิ่มเองมี `tags = null` (= ยังไม่ตัดสิน) · เจ้าของไม่กรอก Tag เอง
   เพราะ Tag คือค่าที่ Ranker ตัดสิน (CONTEXT.md)
3. **เพิ่ม/แก้/ลบได้เฉพาะ Entry `source = manual`** — Entry จาก `public_apis` อ่านอย่างเดียว เพราะ `db:import` upsert ทับ
   · ลบ Entry ที่มี Key ผูกอยู่ไม่ได้ (FK `restrict` มีอยู่แล้ว) · ชื่อ+URL ซ้ำ = ปฏิเสธและชี้ไปที่ Entry เดิม
4. **คำอธิบายของ Entry ต้องเป็นภาษาอังกฤษ** — thai-dict แปลคำค้นไทยเป็นอังกฤษแล้วจับกับชื่อ/คำอธิบาย
   คำอธิบายไทยจะค้นไม่เจอ · Entry อีก 1,871 ตัวก็เป็นอังกฤษ
5. **เดโมใช้ผลของ thai-dict** (เป็นอยู่แล้วตั้งแต่ v0.5.0)

## ผลที่ตามมา
- V1.1 = Jev ranker + Tag อัตโนมัติ + ประวัติการแก้ของ Entry
- ค้นไทยของ V1 พลาด ~6 ใน 20 · คำนอกพจนานุกรม = ไม่เจอ (ข้อจำกัดของ thai-dict ใน ADR-0003)
- ถ้าวัดความแม่นจริงอีกครั้งต้องเขียนชุดคำค้นใหม่ที่ไม่เคยใช้ปรับ

## ทบทวนเมื่อไหร่
- TypeSafe เปิดรับสมัครและ Jev ผ่าน ≥ 15/20 → เปลี่ยน Ranker ค่าเริ่มใน V1.1
- เจ้าของเจอว่าค้นไทยพลาดบ่อยจนใช้งานจริงไม่ได้ → คิดเรื่อง Claude ranker ใหม่
